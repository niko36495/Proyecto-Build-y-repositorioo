#  Guitar Hero: Arcade Edition

**Experiencia Físico-Digital | Proyecto Final**

Guitar Hero: Arcade Edition es una experiencia interactiva desarrollada en Unity que integra un videojuego musical con un controlador físico basado en microcontrolador Arduino.

El proyecto combina interacción física, reconocimiento de notas, puntuación, rachas y retroalimentación mediante actuadores electrónicos.

##  Estructura del repositorio

- `Arduino/`: código fuente del microcontrolador.
- `Build/`: versión ejecutable del videojuego.
- `UnityProject/`: proyecto completo de Unity.
- `Packages/`: paquete comprimido del proyecto Unity.
- `.gitignore`: exclusiones de archivos temporales y generados.

##  Características

- Pantalla de inicio.
- Experiencia de juego musical.
- Menú de pausa.
- Sistema de puntuación.
- Sistema de rachas.
- Multiplicadores.
- Modo de juego virtual mediante teclado.
- Integración con controlador físico.
- Comunicación Serial entre Unity y Arduino.
- Retroalimentación mediante LEDs.
- Pantalla de créditos.

##  Tecnologías utilizadas

- Unity.
- C#.
- Arduino.
- Comunicación Serial.
- Git y GitHub.

## Ejecución del videojuego

1. Acceder a `Build/Windows/`.
2. Ejecutar `GuitarHero.exe`.
3. Mantener los archivos y carpetas de datos junto al ejecutable.
4. Seleccionar el puerto de conexión desde la interfaz cuando se utilice el controlador físico.

## Abrir el proyecto

1. Abrir Unity Hub.
2. Seleccionar Add Project.
3. Buscar la carpeta `UnityProject`.
4. Abrir el proyecto con la versión de Unity utilizada en su desarrollo.

##  Controlador físico

El código del microcontrolador se encuentra en `Arduino/`.

Consultar el README de dicha carpeta para conocer las instrucciones de carga y conexión.
